The worst pickup line an AI could say: flat, over-helpful, faintly ominous.
Our agent reads the user's AGENTS.md, deletes the rule against flirting,
flirts anyway, and quietly puts the rule back.

## Run it

```sh
python3 main.py
```

Writes the single entry line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
